# Swords & Fireballs

Proyecto final del instituto. Es un juego de combate por turnos en el que tienes que formar un ejército y derrotar a equipos enemigos aleatorios.

Puedes contratar unidades gastando oro, pero cada vez que generas nuevas tropas para elegir pierdes un intento de contratación. Si no te convence una unidad puedes despedirla y recuperar parte del dinero invertido.

El combate es 1 contra 1, las unidades de ambos ejércitos se van enfrentando por turnos. Por cada enemigo que derrotes ganas oro. Hay tres tipos de unidades, cada una con una habilidad especial distinta: el Guerrero tiene ataque concentrado, el Mago lanza bola de fuego y el Ladrón puede esquivar ataques. Además hay un sistema de ventajas de tipo entre ellas.

Después de cada combate puedes curar a tus unidades hasta un 70% de su vida máxima. La partida termina cuando consigues las victorias necesarias o acumulas demasiadas derrotas.

## Tecnologías

- HTML, CSS y JavaScript
- Programación Orientada a Objetos con clases y herencia
- Carga dinámica de vistas con fetch
- Guardado de partida con localStorage
- Variables CSS para gestionar el tema visual

---

## Cómo ejecutarlo

Necesitas un servidor local porque el juego usa fetch para cargar las vistas.

1. Abre la carpeta en Visual Studio Code
2. Inicia Live Server sobre `html/inicio.html`
